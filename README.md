2. Bilingual IT Instruction Translator

File: bilingual-it-translator.jsx

A tool that translates English IT/support instructions into clear, professional Spanish, with an option to simplify technical jargon first, for non-technical staff.

What it does:


Takes any IT instruction or notice (e.g., "Your VPN certificate has expired, contact IT to renew it")
Optionally rewrites the English into plain, jargon-free language before translating
Outputs both versions side by side, ready to send to staff


Why I built it:
In hospital IT support environments, language access directly affects how fast an issue gets resolved, a non-English-speaking staff member who doesn't fully understand an instruction will delay fixing the problem or make it worse. Being bilingual myself, I wanted a tool that speeds up exactly that gap.

What I'd improve with more time:
Add audio playback for staff who read better than they scan text, and support a few more languages common in the hospital environments I've supported.
